# Portfolio Florencia Gambero

Portfolio profesional listo para ejecutar con React 19, TypeScript, Tailwind CSS, Vite, React Router, Framer Motion, i18next y Lucide React.

## Ejecución local

1. Instalar dependencias:

```bash
npm install
```

2. Iniciar el entorno de desarrollo:

```bash
npm run dev
```
```

3. Abrir el URL que indica Vite en el navegador.

## Características

- React 19 con TypeScript estricto
- Tailwind CSS con soporte dark/light mode
- Internacionalización con i18next (ES / EN)
- Layout responsive mobile first
- Animaciones con Framer Motion
- Diseño profesional orientado a roles Full Stack, Fintech y IA
- Componentes reutilizables y arquitectura de carpetas limpia

## Personalización

- Reemplaza `public/profile.svg` con tu foto real y actualiza la ruta si deseas usar `profile.jpg`.
- Reemplaza el archivo `public/CV_Florencia_Gambero.pdf` con tu CV real.
- Actualiza los enlaces de LinkedIn y GitHub en `src/data/translations/es.json` y `src/data/translations/en.json`.
